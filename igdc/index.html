Socratic Learning skill

A prompt that turns any AI agent into a learning partner instead of an answer machine. It tests you first, finds your gaps, then guides you with questions until the idea clicks.

socratic-learning.txt · plain text
Download .txt View in browser
// how to use it
  1. Claude Code: save the file as SKILL.md inside a folder named socratic-learning, and add it as a skill.
  2. Any other agent: paste everything below the front matter block into its custom instructions, or at the start of a chat.
  3. Then just say Teach me <topic>. Say revise or test me again later to check what stuck.
